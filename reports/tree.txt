  Responsibilities:                                                                                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                                                                    
  - background worker task                                                                                                                                                                                                                                                                                          
  - per-session debouncing                                                                                                                                                                                                                                                                                          
  - cancellation / supersession tracking                                                                                                                                                                                                                                                                            
  - enqueue on committed text only                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                    
  ### Queue behavior                                                                                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                                                                    
  For each session:                                                                                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                                                                    
  - maintain one active refine job                                                                                                                                                                                                                                                                                  
  - debounce commit stream by 250ms                                                                                                                                                                                                                                                                                 
  - only refine the last committed tail:                                                                                                                                                                                                                                                                            
      - last 48 words                                                                                                                                                                                                                                                                                               
      - plus up to 24 words of left context                                                                                                                                                                                                                                                                         
  - when a new commit arrives before job executes:                                                                                                                                                                                                                                                                  
      - supersede older queued job                                                                                                                                                                                                                                                                                  
  - when a new commit arrives while refine is running:                                                                                                                                                                                                                                                              
      - mark running output stale                                                                                                                                                                                                                                                                                   
      - emit only newest completed result whose revision still matches latest committed revision                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                                                                    
  ### Refiner rules                                                                                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                                                                    
  - never invoked for draft partials                                                                                                                                                                                                                                                                                
  - never awaited in audio loop                                                                                                                                                                                                                                                                                     
  - result applied only if session revision still current                                                                                                                                                                                                                                                           
  - failure logs warning, no user-visible interruption                                                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                                                                    
  ### Refiner payload policy                                                                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                                                                                                    
  refine_final updates only the affected committed tail. It does not rewrite the entire transcript in this phase.

    If# Transcripta Low-Latency Streaming Architecture Plan                                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                                                                                    
  ## Summary                                                                                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                                                                                                    
  This plan replaces the current "partials are treated like disposable segments and finals/refinement share the same broad event path" behavior with a production-grade 2-lane streaming architecture:                                                                                                              
                                                                                                                                                                                                                                                                                                                    
  - Lane A: low-latency live ASR for draft text                                                                                                                                                                                                                                                                     
  - Lane B: async refinement for committed text only                                                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                                                                    
  The implementation is intentionally incremental and keeps the current API/UI working where feasible:                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                                                                    
  - Existing SSE segment events remain during rollout                                                                                                                                                                                                                                                               
  - Existing hotkey websocket remains, but gains explicit draft/commit/refine event types                                                                                                                                                                                                                           
  - Existing settings remain, with one new latency mode selector layered onto current transcription settings                                                                                                                                                                                                        
  - No heavy new dependencies are introduced                                                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                                                                                                    
  The key architecture decision is to use the existing FastChunker + FastWhisperBackend + StreamingInferenceEngine path as the base, rather than switching the app over to the newer audio pipeline classes in app/audio/pipeline_factory.py. Those pipeline classes exist, but the active desktop/API runtime      
  today is still:                                                                                                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                                                                                    
  - regular session: BackendService -> SessionManager -> LoopbackAudioSource + FastChunker + FastTranscriber                                                                                                                                                                                                        
  - hotkey session: HotkeyTranscriptionService -> LoopbackAudioSource + FastTranscriber                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                                                    
  So the lowest-risk path is to upgrade the currently used runtime path rather than do a broad pipeline migration.

  ## Architecture To-Be                                                                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                                                    
  Capture                                                                                                                                                                                                                                                                                                           
    -> VAD-gated rolling audio windows                                                                                                                                                                                                                                                                              
    -> Lane A Live ASR                                                                                                                                                                                                                                                                                              
       -> draft_partial events at 5-15 Hz                                                                                                                                                                                                                                                                           
       -> stabilizer/committer                                                                                                                                                                                                                                                                                      
       -> commit_final events only when stable                                                                                                                                                                                                                                                                      
    -> Lane B Refine Queue                                                                                                                                                                                                                                                                                          
       -> debounce 250ms                                                                                                                                                                                                                                                                                            
       -> supersede older jobs                                                                                                                                                                                                                                                                                      
       -> refine committed tail only                                                                                                                                                                                                                                                                                
       -> refine_final events                                                                                                                                                                                                                                                                                       
    -> UI model                                                                                                                                                                                                                                                                                                     
       committed text + draft suffix + optional refined patch                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                                                                    
  ### Lane A: Live draft streaming                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                    
  - audio is captured continuously                                                                                                                                                                                                                                                                                  
  - VAD decides:                                                                                                                                                                                                                                                                                                    
      - speech start                                                                                                                                                                                                                                                                                                
      - in-speech                                                                                                                                                                                                                                                                                                   
      - hangover / speech end                                                                                                                                                                                                                                                                                       
  - rolling ASR windows:                                                                                                                                                                                                                                                                                            
      - instant mode: 500-700ms window, 180-220ms overlap                                                                                                                                                                                                                                                           
      - accurate mode: 900-1200ms window, 220-320ms overlap                                                                                                                                                                                                                                                         
  - decode settings are cheap for draft updates                                                                                                                                                                                                                                                                     
  - every ASR result is passed through a stabilizer:                                                                                                                                                                                                                                                                
      - computes longest stable prefix vs recent partials                                                                                                                                                                                                                                                           
      - emits only a stable committed prefix and a changing draft suffix                                                                                                                                                                                                                                            
  - only stable text becomes commit_final                                                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                                                                    
  ### Lane B: Async refinement                                                                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                                    
  - refinement only sees committed text, never raw partials                                                                                                                                                                                                                                                         
  - queued on a background worker                                                                                                                                                                                                                                                                                   
  - debounced by 250ms after a new commit                                                                                                                                                                                                                                                                           
  - scoped to recent committed tail:                                                                                                                                                                                                                                                                                
      - last 40-80 words plus 10-20 words context                                                                                                                                                                                                                                                                   
  - new commit supersedes stale queued/running refine work                                                                                                                                                                                                                                                          
  - result emits refine_final                                                                                                                                                                                                                                                                                       
  - if refinement fails, streaming is unaffected

  ## Phase 4: Async refinement queue                                                                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                                                                    
  ### Decision

  - debounce 250ms                                                                                                                                                                                                                                                                                                  
  - cancel/supersede prior job for same session/stream                                                                                                                                                                                                                                                              
  - run RefinerService.refine_text() on committed tail only                                                                                                                                                                                                                                                         
  - publish refine_final                                                                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                                                                                    
  ### Refinement scope                                                                                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                                                                    
  Refine:                                                                                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                                                                    
  - last 60 words committed

  - model_id                                                                                                                                                                                                                                                                                                        
  - mode                                                                                                                                                                                                                                                                                                            
  - used_runtime                                                                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                                                                    
  ### Supersession semantics                                                                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                                                                                                    
  Each queued refine job carries:                                                                                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                                                                                    
  - session_id                                                                                                                                                                                                                                                                                                      
  - stream_id                                                                                                                                                                                                                                                                                                       
  - base_revision                                                                                                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                                                                                    
  If a newer committed revision exists before emit:                                                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                                                                    
  - discard stale result                                                                                                                                                                                                                                                                                            
  - do not emit                                                                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                                                                                    
  ### Failure behavior                                                                                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                                                                    
  - refinement failure logs warning and emits no refine event                                                                                                                                                                                                                                                       
  - streaming lane continues unaffected

  ## Success Criteria                                                                                                                                                                                                                                                                                               
                                                                                                                                                                                                                                                                                                                    
  The implementation is done when all of these are true:                                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                                                                                    
  - draft text appears with perceived latency around 200-300ms for hotkey/mic on supported hardware                                                                                                                                                                                                                 
  - draft update cadence is at least 5Hz and ideally 5-15Hz                                                                                                                                                                                                                                                         
  - final commit stabilizes within 500-1500ms after speech end                                                                                                                                                                                                                                                      
  - committed text never jitters backward                                                                                                                                                                                                                                                                           
  - refinement never blocks draft or commit emission                                                                                                                                                                                                                                                                
  - logs/metrics expose stage timings per segment/revision                                                                                                                                                                                                                                                          
  - both regular session SSE path and hotkey websocket path support the new event semantics                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                                                                                    
  - The current hotkey path still does chunking inside server.py rather than fully sharing SessionManager; that creates some duplicated logic. This plan keeps the duplication but normalizes event semantics.
  - Existing UI already has both SSE and websocket utilities; using both incorrectly could create double-delivery. This plan keeps main-session UI on SSE to avoid that.
  - Overlap + dedupe logic currently happens late in SessionManager; moving to a stable-prefix model must not regress final transcript quality.

  ## Rollback Plan

  1. Revert the new stream event types and keep only segment-based emission in:
      - app/api/service.py
      - app/api/server.py
  2. Revert the stabilizer integration in:
      - app/core/session_manager.py
      - app/stt/fast_engine.py
  3. Revert refinement queue changes independently while keeping the live draft/commit pipeline.
  4. Keep instrumentation even if rolling back event behavior; it is low-risk and useful.

  ## Assumptions and Defaults

  - Main app transport remains SSE for now.
  - Hotkey remains on dedicated websocket.
  - The current active runtime path is SessionManager + FastTranscriber, not the newer pipeline-factory layer.
  - streaming_mode=instant is the new default.
  - No new third-party ASR/refinement dependency is added.
  - Refinement remains local-first via the existing llama.cpp-backed refiner.
  - Draft/commit/refine events are additive; legacy segment stays during migration.

  5. feat(metrics): add per-segment streaming latency traces
